## Handling and privacy

These documents contain summarized project findings, not raw recordings or full transcripts. Do not commit resident databases, ID masterlists, completed forms, resident photos, contact details, credentials, or other confidential source files to this repository. Store client-provided source data only in a client-approved, access-restricted location.

The team must verify that each item listed in the inventory was actually received and that its use is authorized. Keep uncertain interview details under pending clarifications rather than treating them as confirmed requirements.
